# Doc-Ray 1.57.3

Some documents stopped at the analysis step and went no further. They can now be
carried through.

## Who is affected

- **Anyone whose upload halted at "Annotate text".** The document page showed the
  step as needing attention with the message *"Annotate text did not finish"*, and
  nothing after it ever ran — no entity resolution, no search vectors, no images,
  no descriptions. The document stayed readable as plain text and nothing else.
- **Anyone reading grammatical phrase structure**, whether through the API or the
  document view. A small share of recorded phrases may begin later in the sentence
  than they should.
- **Administrators of an installation holding documents in this state.** One
  action per affected document is needed after upgrading; see below.

Search, reading, citations and entity results for documents that completed
analysis were never affected. Nothing recorded was wrong except the phrase offsets
described below.

## What changed

**Analysis no longer stops on unusual sentences.** Doc-Ray records the phrase
structure of every sentence by grouping each word with the words it governs. When
a sentence's grammar came back in an unusual shape — most often from imperfect
text recovered from a scan — the grouping step could leave out the very word the
phrase was built around. Where other words remained, the phrase was recorded as
starting after its own head word. Where none did, the phrase had no extent at all
and analysis stopped for the whole document.

Because the outcome was identical on every attempt, the automatic retries could
not recover it: all three were spent within minutes and the document was set
aside. Measured on a live library on 31 July 2026, four documents between 305,000
and 1,400,000 characters were left in this state, each already holding its full
text.

**Every phrase now contains the word it is built around.** That was always the
intended definition; it is now enforced at both points where a phrase is narrowed
down, and covered by tests for the failure, for the unusual sentence that produced
it, and for the quieter case where a phrase was recorded with the wrong starting
point.

## Action required

**Administrators: re-run analysis on any document showing "Annotate text did not
finish".** Open the document, use **Re-annotate**, then **Re-canonicalize** once it
completes. Scheduled maintenance restores search vectors, images and descriptions
afterwards, because those select the documents that are missing them.

Re-running analysis also replaces that document's recorded phrase structure, which
is how a document processed before this release sheds any understated phrase
offsets. Documents that completed analysis normally need no action unless you read
phrase offsets directly and want them corrected.

Apply the database migrations shipped with this release as usual. No document
needs re-uploading, and no client or integration needs updating.
