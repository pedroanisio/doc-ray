# The Letter & the Hue

A four-chapter visual book on typefaces, colour, arrangement, and applied
colour (93 pages, ~66 plates).

**Second edition — four chapters** (2026-07-02): Chapter III, *The
Arrangement* (after Ernest Batchelder's *The Principles of Design*, 1904,
itself after Denman Ross): tones/measures/shapes × rhythm/balance/harmony,
with the see-saw balance demonstrations solved numerically, a
self-referential plate that weighs one of the book's own pages, and the

## The book

- **Chapter I · The Letter** (pp. 7–36) — essential forms, the pen, serifs,
  anatomy, Johnston's nine qualities, capital proportions, a five-specimen
  taxonomy of typefaces, weight, scale, spacing, measure, and the margin canon.
  Grounded in Edward Johnston, *Writing & Illuminating, & Lettering* (1906).
- **Chapter II · The Hue** (pp. 37–58) — tones/scales/hues, the wheel, the law
  of simultaneous contrast, successive contrast, complementaries, the six
  harmonies, neutrals, value, text on grounds, rubrication, and the closed
  palette. Grounded in M. E. Chevreul's law of simultaneous contrast (1839).
- Source quotations were retrieved from the project's document corpus
  (sentence-level search over the ingested Johnston and Chevreul editions) and
  are attributed in place in the book; a sources page closes the volume.

## Rebuilding

```bash
uv run --project /home/admin/github-mirror/_framework/frameforge python build_book.py
```

Rendering (SVG pages with the text-fit gate, then the merged vector PDF) uses
that same project's tooling:

```bash
cd /home/admin/github-mirror/_framework/frameforge
uv run python tooling/render_fixtures.py <yaml> --out <dir>/svg --check-overflow
uv run --group pdfout python tooling/render_pdf.py <yaml> --out <dir>
```

Set in EB Garamond, Inter, and Fira Mono (all installed system faces). All
plates are drawn vector geometry — nothing is photographed or embedded.
