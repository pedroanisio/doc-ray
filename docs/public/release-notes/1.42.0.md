# Doc-Ray 1.42.0

Version 1.42.0 upgrades semantic search quality, hardens the MCP surface for
production agent traffic, and makes in-app backups an explicit choice.

> Published retroactively on 2026-07-26; this release previously had no public
> note.

## Who is affected

- **Everyone using semantic search** — sentence embeddings moved from a
  hashed bag-of-words to a **learned sentence encoder**: meaning-based
  matches (paraphrases, synonyms) improve materially. Re-embedding the corpus
  is part of the upgrade; results sharpen as it completes.
- **Integrators (MCP)** —
  - health and readiness endpoints, per-principal rate limiting, and a token
    provisioning runbook make the MCP server operable in production;
  - **prompts**: the corpus methodology ships as selectable workflows an
    agent can invoke directly;
  - a new **term-frequency pre-flight** tool reports how common candidate
    search terms are *before* a search, so an agent picks a rare,
    scene-specific term instead of flooding one region of a document.
- **Operators** — an MCP evaluation harness measures the tool surface
  (task success against a live corpus) instead of asserting it.

## Action required

- **Administrators**: in-app corpus backup is now a **feature toggle, off by
  default**. If you relied on in-app backups, re-enable the toggle in your
  deployment configuration; scheduled/external backups are unaffected.
