# Doc-Ray 1.44.0

Version 1.44.0 makes briefing packs rank evidence by **meaning**, adds cost
telemetry for operators, and fixes the Admin Console's operator-health panel.

## Who is affected

- **Everyone building briefings** — briefing packs now rank each document's
  passages by semantic similarity to your topic, so a relevant paraphrase
  surfaces even when it shares no words with your query. The web page, the
  API, and the MCP tool return the same results for the same visible corpus.
  When semantic ranking is unavailable (the sentence stack is not installed,
  or a document has no sentence vectors yet), the pack falls back to keyword
  ranking **and says so** in its `retrieval` and `gaps` fields — never
  silently.
- **Operators** — new per-job cost telemetry attributes pipeline spend, with
  GPU and CPU host-hours priced separately and a reporting script.
- **Administrators** — the Admin Console operator-health panel now reports
  real causes: a misrouted deployment produces an actionable routing error
  instead of a cryptic parse failure, and the panel renders the health
  contract (corpus totals, job spool, issues) correctly.

## Action required

None. No schema change; citations, ordinals, coverage, and budgets in
briefing packs are unchanged.
