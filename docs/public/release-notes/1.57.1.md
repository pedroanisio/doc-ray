# Doc-Ray 1.57.1

Searching the whole library by meaning works again.

## Who is affected

- **Anyone searching by meaning rather than by keyword.** A search across the
  whole library used to fail with a timeout. Only a search limited to a single
  document worked. Both now work, and the whole-library search is once again the
  normal way to use it.
- **Anyone who built a habit around the workaround.** Nothing you already do
  breaks. Searches limited to one document behave exactly as before.

## What changed

**Meaning-based search across the whole library no longer times out.** The
failure was in how the library decided which sentences you are allowed to see,
not in the search itself. That permission check was being repeated against a very
large internal list for every candidate result, and the work grew with the size
of the library until a whole-library search could not finish in the time allowed.
Limiting a search to one document made it finish only because there were far
fewer candidates to check — the check itself was just as slow.

The permission rule is now expressed in a way the database can answer directly,
once per search rather than repeatedly. On the production library the same search
went from failing after more than ninety seconds to answering in a fifth of a
second.

**Who can see what has not changed.** This was a change to how the rule is
evaluated, not to the rule. The permissions are identical, and this was verified
against the live library before and after: the number of results visible to a
given account matches exactly, and an account with no access still sees nothing.

## Action required

None. Administrators apply the database migrations shipped with this release in
the usual way; they change no data, add no columns, and take effect immediately.

Nothing needs to be re-indexed or re-processed, and no client or integration
needs updating — a whole-library search is the same call it always was, just
without the `document_id` you may have been adding to work around the fault.

If you see a timeout from meaning-based search after upgrading, that is now a
genuine fault worth reporting rather than a sign that your search was too broad.
