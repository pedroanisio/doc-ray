# Doc-Ray 1.47.0

Version 1.47.0 adds **allusion edges**: a way to record that one work's entity
points at another — a novel's Paris *alludes to* the real Paris — without ever
merging the two identities.

## Who is affected

- **Curators** — you can now propose a typed, directional link between two
  entities in different lenses: *alludes to*, *depicts*, *references*,
  *adapted from*, or *inspired by*, each with a confidence, a rationale, and
  an evidence document. Links go through a propose → confirm/reject review;
  a proposal is idempotent (re-proposing the same edge does not duplicate it).
- **Integrators (API / MCP)** — new `allusions` read (bidirectional) and
  guarded `proposeAllusion` / `confirmAllusion` / `rejectAllusion` writes,
  mirrored over MCP.

## What to know before relying on it

- An allusion is **never an identity**: it changes nothing about how entities
  resolve, and it is never transitive (A→B and B→C imply nothing about A and C).
- Visibility is strict: an edge is readable only when you can see **both**
  endpoint lenses **and** the evidence document — an edge never reveals an
  entity from a lens you cannot access.

## Action required

None. Existing entities, lenses, and searches are unchanged; allusions are
purely additive curation.
