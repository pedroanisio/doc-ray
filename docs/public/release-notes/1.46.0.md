# Doc-Ray 1.46.0

Version 1.46.0 changes how entity identity works: it is now **projected per
lens** instead of merged globally, so fiction and non-fiction can share one
corpus without corrupting each other's entities.

## Who is affected

- **Readers with mixed corpora** — a fictional character named *Duncan* stays
  inside its work's lens, while the real *Paris* remains one shared identity
  across every history book. Neither pollutes the other, because identity is
  a derived interpretation that can be rebuilt, not a destructive merge.
- **Curators** — projections carry a review status; you can confirm or reject
  how a mention was resolved, and your decision survives re-annotation. When
  the system cannot resolve a mention it says **unresolved** explicitly
  instead of guessing.
- **Integrators** — per-lens entity reads reflect the projection; only a
  collection's designated lens is materialized, keeping cost bounded.

## Action required

None for readers. Administrators managing large corpora should expect a
one-time projection refresh after upgrading; it chains automatically behind
the existing annotation and canonicalization jobs.
